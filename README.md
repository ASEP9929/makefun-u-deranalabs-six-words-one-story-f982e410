## The entry

One complete story in exactly six words:

> Sold the house. Kept the ghosts.

The sale is done — yet what mattered most was never for sale. A whole life is implied in the thing kept behind.

## How it works

`main.ts` (Node 22 stdlib only) writes the six-word story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Run it with:

```sh
node main.ts
```
